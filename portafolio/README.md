# Nicolas Alzate Estrada — Portfolio

A responsive, English-language personal portfolio built with semantic HTML5, CSS3 and vanilla JavaScript.

## Run locally
Open `index.html` in your browser. For the best local development experience, use VS Code with Live Server.

## Included
- Responsive navigation
- Dark / light theme toggle (saved in localStorage)
- Accessible skip link and keyboard focus states
- Reduced-motion support
- About, skills, projects, education and contact sections
- Lucide icons and Google Fonts loaded from CDNs

## Before publishing
- Confirm the project descriptions and repository links.
- Keep `assets/images/profile.png` as the portrait, or replace it with an optimized image using the same filename.
- Test the site on mobile and desktop.
